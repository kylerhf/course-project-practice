## GitHub Practice Reflection
### 1. What is the purpose of a Git commit?

The purpose of a Git commit is to save changes made to a project. These changes can then be referenced later.

### 2. What is the difference between `git push` and `git pull`?

A `git push` pushes changes to a remote repository. A `git pull` downloads the changes from the remote repository into the local project.

### 3. Why might a development team use branches? 
A development team might use branches because they allows developers to work on separate parts of the project without having to worry about overwriting other people's code or interfering with someone else's work. Any conflicts can then be resolved at the end of the process, during a pull request.

### 4. What part of Git/GitHub was most confusing to you?

Some errors with Git/GitHub can be quite confusing. For example, for me, errors relating to not being able to open a pull request due to unrelated histories is confusing.

### 5. How do you think GitHub will help your team manage the course project?
